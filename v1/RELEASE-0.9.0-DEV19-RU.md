# ModKit 0.9.0-dev19 — устойчивое сохранение RE Workspace

Dev19 исправляет падение на больших IL2CPP-проектах в финале RE Workspace и при повторном открытии экрана после анализа.

## Причина

В dev18 Java уже получала компактный результат от Python, но полный `re-analysis.json` всё ещё создавался через монолитный `json.dumps`, то есть на финальном шаге в памяти одновременно находились Python-дерево отчёта и его полная строковая копия. После успешного сохранения `ReWorkspaceActivity` снова загружала весь `re-analysis.json` через `org.json`, создавая ещё одну полную объектную копию уже в Java heap. На крупных проектах это могло привести к убийству процесса системой/OOM: пользователь видел возврат на главный экран, а повторный вход в RE Workspace мог немедленно упасть.

## Изменения

- Полный `re-analysis.json` больше не урезается, но записывается потоково через `JSONEncoder.iterencode`.
- Запись полного отчёта атомарная: итоговый файл появляется только после успешного завершения; временный `.tmp` удаляется при обычной ошибке/отмене.
- Создаётся отдельный bounded `re-analysis.ui.json` со сводкой, shortlist, графом, relationship-строками и ограниченным числом карточек/evidence для экрана.
- `ReWorkspaceActivity` больше никогда не парсит полный RE JSON для отображения.
- UI-индекс имеет `reportState=saving|complete`; во время потокового сохранения экран явно показывает, что полный отчёт ещё пишется.
- При обновлении с dev18 старый полный отчёт без UI-индекса не открывается в Java heap: экран предлагает повторить RE-анализ вместо риска повторного падения.
- Полный набор находок остаётся в полном RE-отчёте и по-прежнему используется Menu Builder/экспортом.
- На сохранении полного отчёта прогресс обновляется примерно каждые 8 МБ.

## Проверки

- split-base regression dev18 сохранён: внешний `libil2cpp.so` + metadata + reusable Rodroid по-прежнему дают IL2CPP xref/context.
- Добавлен regression на bounded UI projection: 120 findings → максимум 48 карточек в UI, 100 controls → максимум 20 строк, evidence ограничен для Java heap.
- Локально: 229 non-CLI тестов зелёные, selftest OK, runtime-check OK. Полный pytest + Android assemble/lint выполняется GitHub Actions.
