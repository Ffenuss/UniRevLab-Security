# ModKit Android 0.6.1

Добавлен отдельный экспорт полного результата Rodroid Il2CppDumper.

- Кнопка «Сохранить полный дамп Rodroid (ZIP)» становится доступна после анализа.
- Выбирать методы и вводить значения для экспорта дампа не требуется.
- В ZIP входят все файлы каталога Rodroid, включая `dump.cs`, `script.json`,
  `stringliteral.json` и `generics_dump.txt`, если Rodroid создал их.
- Также сохраняются полный `analysis.json`, `dump-manifest.json` с размером и
  SHA-256 каждого файла и русская инструкция.
- Временный ZIP удаляется при успехе, ошибке или отмене операции.

Сам экспорт проверен отдельным тестом на временном полном наборе файлов. Python-код
прошёл компиляционную проверку. Базовая версия 0.6.0 до этой доработки проходила
122 теста, Android lint, сборку, проверку подписи и запуск Rodroid в эмуляторе.

APK 0.6.1 собран с Android SDK 34, Build Tools 34.0.0, Gradle 8.9 и JDK 17.
Сборка `assembleDebug` завершена, Android lint прошёл. APK выровнен и подписан
отладочным RSA-ключом по APK Signature Scheme v2. Все 123 Python-теста прошли.
