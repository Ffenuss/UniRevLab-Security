# ModKit Android 0.7.0

- Точный поиск по словам, CamelCase и snake_case вместо совпадения подстрок.
- Синонимы игровых понятий: health/hp/hitPoints, damage/dmg/hurt и другие.
- Системные сборки скрываются из игровых результатов по умолчанию.
- Анализ показывает релевантные поля, свойства и неподходящие для патча методы
  вместе с причиной, а не сообщает, что ничего не найдено.
- Добавлена осторожная смысловая классификация частично обфусцированных имён.
- Кнопка сборки APK теперь остаётся доступной после анализа и объясняет, что
  необходимо выбрать исходный APK игры.
- Полный экспорт Rodroid из версии 0.6.1 сохранён.
