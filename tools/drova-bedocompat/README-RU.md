# Drova Bedo compatibility layer

Обёртка сохраняет Android overlay из `classes3.dex` и исходного `libBedo.so`,
но заменяет список пунктов и обработчик на функции разработчиков Drova 1.3.46 ARM64.

Схема упаковки:

1. Запустить `package_core.py исходный/libBedo.so libCore.so`; скрипт также
   меняет внутренний SONAME, чтобы Android не спутал библиотеку с обёрткой.
2. Собранную библиотеку этого проекта положить как `libBedo.so`.
3. `classes3.dex` оставить без изменений.

Адреса привязаны к исследованному `libil2cpp.so` Drova 1.3.46. Перед другой
версией обязательна повторная проверка RVA.
